# AI背景作成・素材の色調整

フライヤーセットの「AI背景作成・素材の色調整」から利用します。

## 色調整（API不要）

アップロード画像または基本設定で選択中のロゴ／背景を使います。
ゴールド、アイボリー、シルバー、ブルー、レッド、任意の色を選び、置換量と明るさを調整します。
プレビュー作成後、PNGのダウンロードまたは「アセットに保存して選択」で新しい素材として保存します。
元素材は上書きしません。縦横のピクセル数とアルファチャンネルは維持します。
20MB・800万画素以下のPNG/JPEG/WebPに対応します。GIFには未対応です。

## 背景のAI生成（管理者の接続設定が必要）

Streamlit CloudのSecretsに、既存項目を残したまま以下のセクションを追加します。
実際のキー・利用コードはリポジトリやチャットへ書かないでください。

```toml
[openai]
api_key = "OpenAIのAPIキーを管理画面で設定"
access_code = "アプリで生成を使う人にだけ共有する利用コード"
```

環境変数 `OPENAI_API_KEY` と `AI_STUDIO_ACCESS_CODE` でも設定できます。
両方が設定されていない場合は生成ボタンを無効にします。色調整は引き続き使えます。
利用コードはAPIキーと異なる値にしてください。キーやコードは画面・ログへ出力しません。
このコードは共有アプリ内の簡易利用制限です。公開利用や大規模利用へ拡張する際は利用者認証とアカウント側の予算上限を設定してください。

指示と色合いを選び、利用コードを入力して生成ボタンを押すと1枚だけリクエストします。
生成APIの利用料が発生します。参考背景を添付すると、構図を合わせる編集APIを使用します。
指示と参考画像はOpenAIへ送信します。背景に文字や人物を生成せず、中央を暗めにする指示をアプリ側で付けています。
同じ構図の別色が必要な場合、前に作った背景を参考画像として指定できます。AI編集では完全な形状一致は保証しません。厳密な色違いは色調整を利用します。

モデル `gpt-image-2`、1024×1280px、medium、PNG、1枚に固定。
自動リトライは行いません。タイムアウト時は利用状況を確認してから再実行します。
保存は生成とは別操作です。アセット選択をイベントに確定し完成画像を更新するには「プロジェクトを保存する」を使います。

API仕様の参照元:
- https://developers.openai.com/api/docs/guides/image-generation
- https://developers.openai.com/api/reference/resources/images/methods/generate
- https://developers.openai.com/api/reference/resources/images/methods/edit

## 今回の範囲と次の段階

今回追加するのは背景生成・素材色調整・プレビュー・アセット保存・選択です。
概要テキストとPDFから全体を組み立てる自動制作エージェントは今回には含みません。
既存の概要解析、PDFプレビューと部選択、時刻計算、アーティスト照合、画像生成をまとめることで次段階として実装できます。
その際は抽出内容を下書きに反映し、不明な時刻・料金・名前を勝手に補完しない確認工程を設けます。
