# AIおまかせ制作

ワークスペース上部「✨ AIおまかせ制作（新規プロジェクト）」から利用する。

1. 公演概要を貼り付け、タイムテーブルのPDF／.xlsx／CSVを選ぶ。素材作成と共通の利用コードを入力し「資料をAIで解析する」を押す。
2. 読み取り結果の日付・料金・出演名・時刻を確認し、必要なら修正する。控室情報は取り込まない。登録アーティストとの自動照合は表記正規化後の一意の一致だけで行い、不一致は登録名を選ぶか未登録の枠にする。
3. 制作する部にチェックする。1部のみなら通常イベント、2部以上なら複数部イベントになる。元の部名は保持する。
4. デザインの希望、背景、ロゴを設定する。背景はAI生成・既存アセット・アップロード・指定なし、ロゴは標準BASIC・既存アセット・アップロード・イベント名の文字ロゴを選べる。元ロゴの色変更は画像生成ではなく画素の変換で行う。
5. 完成プレビューを生成し、グリッド版・タイムテーブル版・概要テキストを確認する。ZIPでも取得可能。
6. 「新規プロジェクトとして保存して編集画面を開く」で素材をアセット登録し、新規プロジェクトと出演行を一括保存する。通常のフライヤーセット編集で調整を続けられる。

既存イベントの編集中に未保存の変更がある場合は、先に上部の保存ボタンで保存する。入力内容を変えた後はプレビューを再生成するまで新規保存できない。保存結果が不明の場合は重複登録を避けるため再保存を止めるので、プロジェクト一覧を確認する。

## 対応範囲

- 文字を選択できるPDF（10ページ以内）、Excel `.xlsx`（6シート・各1000行×40列以内）、CSV（UTF-8/BOMまたはCP932・1000行以内）。10MB・抽出文字6万字まで。
- Excel数式は実行せず、保存された計算結果を読む。画像だけのPDF、旧 `.xls`、日付またぎは未対応。
- 1〜6部、合計100出演行まで。不明な時刻・日付は推測せず確認する。出演開始・終了が資料中の根拠と一致しない解析結果は拒否する。AIの読み取りが完全とは限らないため、プレビュー前の確認は必須。
- 同一部の最初の出演はSTARTと一致する必要がある。出演間の空白は転換時間になる。
- 物販の不明な行は時間を空欄にする。通常イベントに終演後物販のまとめ枠がある場合は、対象アーティストの「終演後」を指定する。
- 出力は既存デザインに基づく自動配置。完成後も各編集項目を使える。自由な指示で任意のレイアウトを組み立てる汎用チャットではない。

## 接続と費用

素材作成機能と共通の `OPENAI_API_KEY` / `AI_STUDIO_ACCESS_CODE`、またはStreamlit secretsの `[openai] api_key / access_code` を使う。ブラウザにはAPIキーを出さない。

「資料をAIで解析する」1回につき `gpt-5-mini` の構造化出力APIを1回呼ぶ。概要と抽出した資料テキストをOpenAIに送信する。背景AI生成を選ぶ場合は別途既存の画像生成APIを呼ぶ。同じ背景条件でのプレビュー再生成はセッション内の生成済み背景を再利用する。失敗時の自動再試行はしない。料金はAPIの利用量・設定で変わる。

検証ではAPI応答・アセット登録・新規保存をモック化し、課金する生成や本番DBへの書き込みは行っていない。実際のAPI接続は公開反映後に利用者の明示操作で確認する。

背景色の初期値は「指示に合わせる」。標準ロゴは登録名 `ROCKFIELD ULTRA LIVE - BASIC` が一意に存在する場合だけ選択する。ロゴ素材の未選択時は明示的なエラーとし、別のロゴに自動置換しない。概要側の出演者名も照合対象に含めるため、略記の修正後も概要のグリッド順を維持できる。27組の場合は5・5・5・6・6の5行を初期配置にする。
